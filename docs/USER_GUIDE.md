# 🎯 User Guide

## 1. Load image

1. Click **Načíst obrázek**
2. Select image
3. Click **Spustit AI**

---

## 2. Camera

1. Click **Kamera**
2. Click **Zachytit**
3. Click **Spustit AI**

---

## 3. Results

### Top panel

* Number of dice
* Sum of values
* Average confidence
* Inference time

### Image

* Colored bounding boxes
* Labels per dice

### Right panel

* List of detections
* Confidence values
* Bounding box info

---

## 4. Tips

* Good lighting
* Non-overlapping dice
* Sharp image
* High contrast background

---

## 5. Troubleshooting

### No detections

* Improve lighting
* Increase image quality

### Wrong value

* Ensure dice face is visible

### Slow inference

* Use smaller images

---

## 6. Reset

Click **Vyčistit**
